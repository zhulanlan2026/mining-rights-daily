# 锂矿日报

生成日报时把本文件读进提示词。改版式、口径时只改这里。

## 必须章节

日报必须包含以下二级标题，顺序固定：

- 新闻摘要
- 储量数据
- 价格走势
- 风险提示
- 引用

配置了 DeepSeek 密钥时，在「引用」之前增加「简要研判」。没有密钥时不写这一节。

## 口径

- 新闻最多三条，每条带链接。正文来自 `fetch_article`；读不到正文时保留检索摘要，并写明失败。
- 储量只来自 `mineral-pdf`。Pilbara 锂使用 `catalog:pilgangoora-ni43101-sample`。这是合成样本，必须保留「不是正式披露」的说明。
- 价格只来自 `lme-price`。序列是演示参考价，不是 LME 结算价，也不是辉石精矿价。请求日晚于序列时写明实际采用的交易日。
- 风险只能根据已经取到的新闻、储量和价格来写。某个工具失败时，该段写「未获取到数据」，禁止补造吨位或价格。
- 引用里写实际取到的新闻 URL 和 PDF 源链接。

## 简要研判

只复述上面章节里已经出现的事实，并指出精矿与氢氧化锂参考价不是同一合约。不得新增数字、吨位、价格或日期。
